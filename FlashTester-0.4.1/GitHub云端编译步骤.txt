FlashTester 0.4.1 简体中文版 — GitHub 云端编译
================================================

本目录已加入 GitHub Actions 工作流：.github/workflows/build-windows.yml
每次推送到 main 分支，或在 Actions 中手动运行工作流，GitHub 都会在云端 Windows 环境编译。

操作步骤（无需在本机安装 Rust）：
1. 登录 https://github.com/
2. 点击右上角 +，选择 New repository。
3. 仓库名称填写 FlashTester-zhCN；选择 Public 或 Private 均可。
4. 创建仓库后，选择 Add file -> Upload files。
5. 将本压缩包解压，把里面 FlashTester-0.4.1 文件夹内的全部文件和文件夹上传到仓库根目录。
   注意：需要包含隐藏目录 .github；如果网页未显示隐藏目录，请在文件管理器开启“显示隐藏的项目”，
   或使用 GitHub 网页 Add file -> Create new file 创建 .github/workflows/build-windows.yml，
   再复制本包中同名文件的内容。
6. 点击 Commit changes。
7. 打开仓库顶部 Actions 标签页。
8. 进入 “Build FlashTester 0.4.1 Chinese (Windows)” 工作流，等待绿色成功标记。
9. 点击成功的运行记录，在页面底部 Artifacts 下载
   FlashTester-0.4.1-简体中文版-Windows-x64.zip。
10. 解压后运行 FlashTester_0.4.1_简体中文版.exe。

若编译失败：
- 点击失败的运行记录，再打开 build-windows job。
- 将红色错误部分截图或复制给我，我会据此修正源码或工作流。

安全提醒：
- 第一次运行请先只做设备信息查看和只读扫描。
- 完整容量测试、整盘写入、修复/格式化等操作可能清除数据，务必先备份并核对目标磁盘。
- GitHub Actions 构建成功不等于硬件检测功能已在你的电脑上完成实测。
