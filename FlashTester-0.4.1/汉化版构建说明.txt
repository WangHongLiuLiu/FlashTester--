FlashTester 0.4.1 简体中文界面版（源码构建包）
================================================

本包基于用户提供的 FlashTester 0.4.1 源码制作，主要翻译图形界面、操作说明、
常见状态、报告/SMART 标签及部分命令行提示，并加入中文字体回退。当前为第一版界面汉化，少量底层诊断/错误详情或设备厂商字段仍可能显示英文；后续可根据运行截图继续补齐。

重要说明
--------
1. 这是汉化源码包，不是已编译的 flashtester.exe。
2. 当前制作环境没有 Rust/Cargo 和 Windows 编译工具链，因此无法在这里生成并验证 Windows EXE。
3. 未修改磁盘检测、写入、容量估算、备份恢复等核心算法。
4. 首次运行任何写入型检测前，请先备份数据，并仔细确认目标磁盘。
5. 中文字体文件 AR-PL-Gb.ttf 使用 AR PL 字体系列，许可文件请查看 assets/fonts/AR-PL-Gb-LICENSE.txt。

Windows 11 本机编译
-------------------
1. 安装 Rust stable（https://rustup.rs/）。
2. 安装 Visual Studio 2022 Build Tools，并勾选“使用 C++ 的桌面开发”。
3. 解压本包，在解压目录打开 PowerShell。
4. 执行：
       cargo build --release
5. 编译成功后，程序位于：
       target\release\flashtester.exe

建议先用只读功能检查界面和设备识别，再考虑进行任何写入测试。
如果编译报错，请把完整错误日志发回，我可以继续修正汉化源码。
